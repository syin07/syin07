# GitHub profile README (syin07)

This repo is my GitHub profile page. `README.md` renders at github.com/syin07.

## Layout
- `README.md`: the profile. GitHub strips `<style>`, `<script>` and most attributes, so layout uses plain HTML tables, `align`, and `width`.
- `assets/banner.svg`: animated header. Generated, do not hand-edit: change `scripts/banner.py` and run `python3 scripts/banner.py assets/banner.svg`.
- `assets/btn-*.svg`: the link buttons under the banner, one image per button. Same geometry as shields.io `style=for-the-badge`, in neutral greys (see Design rules). Generated by `python3 scripts/buttons.py`; add or rename a button in its `BUTTONS` list, then wrap the image in a link in `README.md`.
- `assets/divider.svg`: animated section divider (a pulse travelling along a dotted line). Generated by `python3 scripts/divider.py assets/divider.svg`; takes the same optional freeze time as the banner.
- `assets/activity.svg`: contribution grid, one square per day for the last year, with a slow ripple crossing it. Written daily by `.github/workflows/activity.yml` running `scripts/activity.py`. Never commit it by hand. Preview the design with `python3 scripts/activity.py --demo /tmp/activity.svg` (add a number of seconds to freeze the animation there).

## Design rules
- Light background only. One accent colour, amber: `#F59E0B` for shapes (bars, cursor), and `#B45309` where the accent has to be read as small text. Body text `#1F2328` (GitHub's own), secondary text `#6B7280`, tracks `#E5E7EB`. No blue or purple.
- Buttons and badges are neutral, not amber: the link buttons are `#F6F8FA` with a `#D0D7DE` hairline border, `#1F2328` text and `#57606A` icons, and the shields.io tool badges use the same `F6F8FA` fill and `57606A` logos. Don't bring back amber-and-dark buttons; that pairing belongs to another site and this profile should not be associated with it.
- The banner sits on plain `#FFFFFF` with no frame or tint, so it blends into GitHub's light page and the row of link buttons under it reads as part of the same header. Its layout is centred on the vertical midline.
- Restrained: no typing-SVG services, trophy or stats cards, visitor counters, or rainbow badge walls.
- Every image is a self-contained SVG in this repo (CSS animation only, no external fonts or scripts). The only third-party images allowed are the shields.io tool badges.
- Animations must respect `prefers-reduced-motion` and look complete when frozen.
- Only list projects that have a public repo to link to. Don't invent results or metrics.

## Checking changes
- Open the SVG directly in a browser to watch the animation. To inspect one moment, pass a time in seconds as a second argument: `python3 scripts/banner.py /tmp/frame.svg 8.2`.
- GitHub serves SVGs through an image proxy and caches them for a few minutes; a hard refresh may be needed after pushing.
